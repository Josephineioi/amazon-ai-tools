# 亚马逊产品利润计算器

这是一个适合亚马逊跨境电商新手使用的简单网页工具。它不需要安装复杂软件，只要用浏览器打开 `index.html` 就可以使用。

## 功能

你可以输入：

- 产品售价（美元）
- 产品采购成本（人民币）
- 国内物流费用
- 国际运费
- 亚马逊佣金比例
- FBA配送费用
- 广告费用
- 汇率

工具会自动计算：

- 总成本
- 单个产品利润
- 利润率
- ROI

## 如何在 Mac 运行

### 方法一：直接用浏览器打开（最简单）

1. 打开这个文件夹。
2. 找到 `index.html` 文件。
3. 双击 `index.html`。
4. 系统会用 Safari、Chrome 或其他浏览器打开网页。
5. 修改输入框里的数字，结果会自动更新。

### 方法二：用终端打开

1. 打开 Mac 上的“终端”。
2. 进入项目文件夹，例如：

```bash
cd /path/to/amazon-ai-tools
```

3. 运行：

```bash
open index.html
```

## 计算公式

- 销售收入 = 产品售价 × 汇率
- 亚马逊佣金 = 销售收入 × 佣金比例
- 总成本 = 采购成本 + 国内物流 + 国际运费 + 亚马逊佣金 + FBA配送费 + 广告费
- 单个产品利润 = 销售收入 - 总成本
- 利润率 = 单个产品利润 ÷ 销售收入 × 100%
- ROI = 单个产品利润 ÷ 总成本 × 100%

## 文件说明

- `index.html`：网页结构和输入区域
- `styles.css`：网页样式，让界面更美观
- `script.js`：计算逻辑
